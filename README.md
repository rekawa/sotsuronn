# ライフログ統合型回想支援システム (MEAMs Web Application)

写真の撮影日時（Exif）と音楽サブスクリプション（Spotify / Apple Music）の再生履歴を自動照合し、当時の思い出の楽曲（TOP5）とともに写真スライドショーを鑑賞できる回想支援Webアプリケーションです。

## 主な機能
- **再生履歴の自動解析**: Spotify (JSON) および Apple Music (CSV) の再生履歴に対応。
- **高精度な写真撮影日時（Exif）自動解析**: `exifr` を採用し、iPhone標準の HEIC/HEIF 形式をはじめ、JPEG, PNG, WebP などあらゆる写真フォーマットのメタデータ（`DateTimeOriginal`, `CreateDate`, `GPSDateStamp` 等）から正確な撮影日時を優先抽出。
- **日別TOP5楽曲再生 & スライドショー**: 当時最も聴いていた楽曲TOP5の個別再生および写真の自動スライドショー。
- **Billboard JAPAN 週間TOP10 公式実データ完全収録 (2017年10月4日週〜2026年9月 / 全469週)**: ストリーミング集計開始初週（2017年10月4日公開週）から最新週までのBillboard JAPAN Hot 100公式週間TOP10ランキングを1週の欠損もなく完全収録。写真の日付と自動連動して当時の流行曲を正確に振り返り・手動追加可能。
- **プライバシー保護**: すべてのデータ処理はブラウザローカル（IndexedDB）で完結し、外部サーバーへのアップロードは一切行いません。
